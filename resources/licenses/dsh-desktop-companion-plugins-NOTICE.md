# dsh_desktop companion components

Earlier versions imported companion components from `myYangyunfan/dsh_desktop`
(original reference commit `0289da22c49ce02a98978e14fe7c4f8e2d0dc7a3`).
The original reference license is retained for provenance.

No optional companion plugins or compatibility runtime are included now.
The plugin market has also been removed. This file records historical provenance
only, not the current plugin inventory.

The upstream repository license is bundled as
`dsh-desktop-reference-LICENSE`. Component-specific licenses and notices remain
inside their respective plugin directories.
