# MyDSH 0.0.2 体验检查

检查日期：2026-09-13。本报告记录发布前的本地验证；0.0.2 随后已发布。当前维护状态见 [项目状态](../PROJECT_STATUS.zh-CN.md)。

## 本轮修复

- 设置弹窗限制 Tab / Shift+Tab 焦点，关闭后恢复到入口；兼容弹出的菜单和列表。
- 无可用会话历史时禁用返回、前进按钮，取消禁用按钮的悬停反馈。
- 插件市场安装增加五分钟超时与取消入口；等待安装进程退出后再回滚，退出软件也会先取消安装并等待还原。
- 安装状态和失败信息保留在主进程，重新打开设置后仍可读取；回滚失败不会被误报为正常取消。
- 桌面端更新提供检测、等待确认、下载百分比、校验、安装及取消状态；任务栏同步下载进度。
- 取消下载或校验失败清理临时安装包；用户确认自动发现的更新后，失败也会显示提示。
- 初次加载不再误报插件市场未安装；桌面端版本优先使用预加载的本机元数据。
- 关于页面复用启动时已确认的 Harness 版本，不再重复执行工具链探测来阻塞元数据和更新状态。
- 启动失败显示简短错误、重新启动和安装说明入口，完整错误保留在日志输出。

## 验证

- 桌面测试：231 项通过，0 失败，0 跳过。
- TypeScript 检查和 Windows x64 本地打包通过。
- 实际 Electron 窗口：侧边栏展开/收起、图标对齐、标题栏遮罩、设置边界、关于页面滚动和重复打开通过。
- 设置页检查包括通用设置、快捷键、终端、模型、插件、Agent 预设。
- 1280 和 960 像素宽度下没有发现设置内容横向溢出。
- 连续 30 次 Tab 和 30 次 Shift+Tab 未进入背景界面，Escape 关闭后焦点返回设置按钮。
- 本地 HTTP 测试验证下载百分比、取消和校验失败清理；临时工作区验证安装取消回滚；真实子进程测试验证取消与超时退出。

## 验证边界

未实际下载并执行远程发布的新版安装程序，未修改用户模型设置，也未在干净机器上重装系统依赖；这些发布前场景不能由本轮回归替代。
本记录覆盖本次检查发现的问题，不代表对所有硬件、网络和第三方插件组合的无缺陷保证。
