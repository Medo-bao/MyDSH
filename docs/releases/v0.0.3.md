## 更新内容

1. 修复了若干 bug，优化了实际体验。
2. “关于 MyDSH”新增关闭行为设置，默认最小化到托盘，也可选择直接退出。

## 安装说明

- Windows x64；安装包不包含系统运行环境。
- 需要 Node.js 24+、Corepack/pnpm 11.7.0 和 DSH 0.1.5-rc.2。
- 保留现有会话和配置；请核对随包的 SHA256SUMS。
- 自绘最大化按钮不提供原生悬停分屏菜单，可使用 Win+Z。
