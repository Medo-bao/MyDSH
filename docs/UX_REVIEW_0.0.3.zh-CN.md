# MyDSH 0.0.3 体验检查

日期：2026-09-14。以下为 0.0.3 发布前的本地验证记录；发布构建另由 GitHub Actions 校验。

## 变更

- “关于 MyDSH”新增关闭行为，使用统一配置文件持久化；首次启动和未含此字段的旧配置默认最小化到托盘，保留用户明确选择的直接退出。托盘不可用时仍退出，避免隐藏后无法唤回。
- 托盘关闭不影响显式退出和运行时重启。退出状态在等待安装取消之前置位，避免把有意关闭误报为崩溃。
- Windows 三个窗口按钮改为同布局的界面控件，使设置遮罩能真正模糊并禁用它们。最大化、还原状态同步；关闭设置后恢复操作。
- 插件市场 1.46.1 原先会创建独立重启助手，然后杀死当前 Harness，桌面端据此弹出异常退出提示。现保留市场原有同源、操作状态等校验，只适配 `scheduleRestart` 的进程交接，由受管理子进程 IPC 请求桌面端重启。
- 市场适配只在受桌面端管理且 IPC 连接存在时生效，普通 CLI 使用仍走原行为。文件采用原子替换，避免修改 pnpm 存储中的硬链接。重复应用不改变文件；不认识的重启接口明确报错，不静默做不受管理的重启。
- 重复重启合并；等待桌面市场安装和桌面更新结束；重启失败提供重试或退出，不留在无操作的加载界面。
- 移除“关于”页空状态提示占位，减少常见窗口尺寸下不必要的滚动。

## 验证

- 主进程和 overlay 类型检查通过；237 项桌面回归全部通过，0 失败、0 跳过。
- Windows x64 打包通过，程序文件版本为 0.0.3。
- 实际 Electron 在 1280x1000、1280x800、960x640 验证设置位置、遮罩、键盘焦点及“关于”布局；三个窗口按钮在设置打开时均禁用，关闭后恢复。
- “关于”关闭偏好保存及切换页面后重新读取通过；本机最终设置为最小化到托盘。
- 实际点击关闭后原生窗口不可见且进程仍存活，再次启动程序唤回原窗口，通过。
- 真实市场重启接口返回 202，桌面端管理的 Harness 重新就绪，Electron 进程保持不变，无异常退出弹窗。
- 一次 npm 检测受网络超时影响，后续复测通过；测试也核对网络失败时必须有明确错误提示。

## 边界

- 本次没有更新 Harness 或插件市场版本，也没有安装用户未要求的新插件。
- 当前市场重启适配验证对象为 1.46.1；未来市场改变该接口时需要同步适配。
- 自绘最大化按钮不提供原生按钮悬停时的 Windows Snap Layout 弹层；系统 Win+Z 和窗口拖动贴靠仍由 Windows 管理。
- 未覆盖全部外部插件、付费模型请求、干净 Windows 首次安装和发布后的自动更新链路。
